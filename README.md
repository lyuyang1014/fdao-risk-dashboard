# FDAO / META 风险驾驶舱

独立的 BNB Chain 链上风险监控项目，用于观察 FDAO / META 的新增资金、退出压力、钱包结构，以及推荐团队图谱。

公开页面：`fdao-monitor/index.html`

数据每 10 分钟由 GitHub Actions 自动刷新。链上关系会明确区分：

- A 级：calldata、event 或 storage 直接确认；
- B 级：推荐或级差奖励流向反证；
- C 级：同区块、短时间同金额等批量行为推断；只显示为行为簇，不计入推荐树。

当前公开 RPC 无法经济地批量回溯每个钱包的原生币 gas 来源；在没有可复核证据前，不把普通转账或资金来源直接认作推荐关系。

`risk-assessment.json` 另外提供：

- 退出池流动性、FDAO 持有 LP 折算价值、合约显示 TVL 与资产覆盖率；
- 排除当天未完成数据后的 3/7/14 日资金和新钱包增长；
- 真实解押事件中的 30/60/90 日释放选择与 30%/20%/10% 链上手续费；
- 已知用户钱包的实时解押报价、参考盈亏与 SENTIS 保本价格；
- 基于 LP 覆盖、新增资金、奖励压力和真实解押的黄/橙/红风险触发条件。

美元成本不是链上原生事实：SENTIS 投入量由交易回执确认，历史美元成本只在有用户同期价格证据时作为参考显示。

本项目只用于风险观察，不构成投资建议。推算结果不会冒充项目方官方数据。
